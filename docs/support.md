# OutLoud Support

For help, bug reports, or feature requests, [open a GitHub issue](https://github.com/ClarkOhlenbusch/OutLoud/issues/new/choose).

Include:

- iPhone model and iOS version
- OutLoud version
- The step that failed
- Relevant logs from the `com.clarkohlenbusch.outloud` subsystem, with any personal information removed

Common fixes are also available in the [installation guide](https://github.com/ClarkOhlenbusch/OutLoud/blob/main/INSTALL_ON_IPHONE.md#common-fixes).
